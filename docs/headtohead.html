How this works, and what it doesn't cover yet

  • Forced-pick question: "If you had to pick one for a filmmaker generating AI video, Runway or {rival}?" Asked in both name orders, 5 fresh runs each (60 answers total).
  • Open comparison question: "Runway vs. {rival}: which should I choose?" Asked once per order (12 answers) — this is where the reasoning notes above come from. It is not repeated, so a single odd answer could be noise.
  • Mixed source, disclosed: Pika's 10 forced-pick runs and 9 of Luma AI's 10 came from ChatGPT's web app, logged out, no memory or personalization. Partway through, ChatGPT's anonymous-usage cap blocked the browser session entirely (confirmed with a control test on an unrelated message, and it persisted over 11+ hours). The remaining 1 Luma AI run, all of Kling AI/Sora/Veo/HeyGen (40 runs), and all 12 open-comparison runs came from the OpenAI API (gpt-4o) directly — same question text, but no browsing and a different underlying model than ChatGPT's web app serves.
  • The headline finding: this isn't really a 6-way competitive sweep. The model only demonstrated real product knowledge for Luma AI and HeyGen — it described both accurately and specifically. For Pika, Kling AI, Sora and Google Veo, it either misidentified the product (Pika as a color-picker tool) or had no idea what it was (Kling AI, Sora, Veo all drew hedging, generic non-answers — one run on Veo stated outright "I'm not aware of a product named 'Google Veo'"). Runway's 10-of-10 sweep against those four rivals is a visibility gap in the model's training data, not a judged comparison.
  • All 6 rivals show the exact same 5–0/5–0 split by order, so there's no order effect to report here — unlike the Hostaway project, where two rivals fully flipped by which name came first.
  • Not yet covered: pricing, integrations, onboarding, setup and support as separate scored dimensions — the open-comparison answers made almost no specific, checkable claims (no citations at all from the API route), so there isn't a real "worth checking" fact sheet for this project the way there was for Hostaway. Also not covered: any run while logged in, or any engine besides ChatGPT/GPT-4o.
